# HealthDoc 第五轮优化实施说明（schema v10）

> 实施日期：2026-07-27。本文是第五轮需求到代码、数据、测试和发布的追踪基线；如与旧版文档冲突，以本文及当前 schema v10 代码为准。

## 1. 交付范围

| 领域 | schema v10 实现 |

| 亲友授权 | `POST /api/friends` 仅接受健康身份码和关系；待授权姓名脱敏，授权后统一输出真实姓名，不暴露用户名 |

| 通知 | `user_notifications` 提供分页、未读数和已读操作；邮件 Outbox 支持幂等、领取、失败重试 |
| 报告附件 | 14 个标准附件槽、套餐版本必需槽、槽位数量限制、单报告 12 份上限、EXIF 清除和机构批注 |
| 指标/OCR | 104 个成人体检指标、中文/英文/旧称别名、单位和科普；性别/年龄参考规则；七类结果方向；OCR 表头、单位、参考范围和 H/L 标志复核 |

## 2. 关键隐私与状态规则

1. 健康身份码只精确匹配启用的普通用户；本人、机构、管理员和重复关系均不能添加。
2. 代预约人只能提交亲友身高和体重，不能读取病史；服务端在预约事务中读取亲友资料并生成不可回写的机构可见快照。
3. 预约准备说明的医学内容只来自机构审核通过的套餐版本须知；平台只补充身份证原件、预约凭证、病历本、既往报告/影像和用药清单等通用携带项。
4. `institution_cancelled` 必须包含固定原因代码和文字说明。替代分院在取消时写入通知快照，后续机构资料变化不会改写既有通知。
5. 管理员改密只适用于有有效邮箱的普通用户。提交后新密码立即生效、`token_version` 递增；邮件失败不回滚密码，可重试同一通知且不再次修改密码。邮件成功后清除 Outbox 明文载荷。
6. AI 不向模型发送联系方式、健康身份码、过敏史或既往史。机构推荐不读取健康档案；“我/我的”只选本人，明确提到已授权亲友真实姓名时才选择该单一成员。

## 3. 数据库与兼容策略

SQLite 使用 `scripts/upgrade_local_database.py` 原子升级至 `PRAGMA user_version=10`；openGauss 使用 Alembic 修订 `20260726_schema_v10` 或等价的 `scripts/migrate_schema_v10.py`。迁移要求源库为 v9，并校验新增表、列、外键、唯一键、检查约束及行数。

主要新增表：

- `user_notifications`
- `report_asset_types`
- `package_version_asset_requirements`
- `indicator_reference_rules`

主要新增字段：

- `appointments`：身高、体重、BMI、联系方式、过敏史、既往史、快照时间、取消责任/原因；
- `report_assets.asset_type_id`；
- `report_indicators.result_status`。

旧 `invalidated` 预约迁移为 `no_show`；旧预约资料字段为空并在界面显示“历史预约未采集”；旧亲友关系保留授权状态。`is_abnormal` 继续作为兼容字段，由 `result_status` 派生。

## 4. 指标依据与判定边界

指标目录以国家卫生健康委《成人健康体检项目推荐指引（2025年版）》为主要范围依据，该指引适用于 18 岁及以上成年人，并列出体格、血尿常规、生化、甲状腺、心电、影像、肺功能和骨密度等项目：

- <https://www.nhc.gov.cn/yzygj/c100068/202511/4feaeb6de63e44cb9fd4ac8f579ca279.shtml>
- <https://www.nhc.gov.cn/zwgkzt/pyzgl1/201303/906048b809e04849b0f14daeea92ff2c.shtml>
- <https://www.nhc.gov.cn/ewebeditor/uploadfile/2013/08/20130808135715967.pdf>

系统遵循“机构原始参考范围优先、系统性别/年龄规则其次、通用范围再次”。无可靠规则时内部保留 `unknown` 以供审计，但用户界面不显示状态标签。身高、体重和臀围等描述性测量值不单独判定正常或异常；体重相关风险由 BMI 表达。平台参考规则用于演示和趋势提示，不替代出具报告的医疗机构判断。BMI 使用中国成年人分层显示偏低、正常、超重和肥胖；定性项目使用阴性、阳性或异常。

趋势页面不向用户展示“描述性测量值”“暂无统一参考范围”或参考范围来源优先级说明。存在可靠上下限时统一使用“参考范围”标题；不存在上下限时图表占满内容宽度，不额外保留空白说明栏。

## 5. 测试与发布门禁

发布前必须依次通过：

```powershell
Set-Location backend
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts\upgrade_local_database.py --check-only
.\.venv\Scripts\python.exe scripts\validate_v10_demo.py
.\.venv\Scripts\python.exe scripts\refresh_demo_media.py --check-only

Set-Location ..\frontend
npm test -- --run
npm run build
npm audit --omit=dev
```

演示服务器使用 `scripts/deploy-server.ps1 -SyncDemoDatabase`。远端脚本先停止写入并备份 openGauss 物理目录、上传目录和 root-only 环境配置，再导入 SQLite v10 演示快照与清单媒体；迁移、RAG、API、Apache 或通知 worker 任一验收失败，均恢复数据库、上传文件、环境和上一代码版本。

本轮目录搜索与分页增强不改变 schema。`GET /api/organizations` 新增可选 `q` 参数，采用字面量、不区分大小写的包含匹配；`%`、`_` 等输入不会作为 SQL 通配符。`GET /api/booking-groups` 继续使用 `page/page_size/start_date/end_date`，默认 `page_size=10`。
