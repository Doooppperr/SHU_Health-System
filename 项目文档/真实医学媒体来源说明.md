# 真实医学媒体来源与验收说明

## 数据边界

HealthDoc 的账号、指标、报告故事、预约和机构均为合成演示数据。报告附件中的医学图片改用 Wikimedia Commons 上开放授权的真实检查样例，图片不对应系统用户，也不得用于诊断。

当前保留 8 个实际使用且已审计的医学源。它们按标准槽位映射为：`US_THYROID` 1 份、`US_ABDOMEN` 3 份、`SPIROMETRY` 2 份、`ECG_12` 5 份、`CHEST_IMAGE` 3 份、`ECHO_HEART` 2 份、`BLOOD_MICROSCOPY` 3 份。经审核的同一开放素材可在多个合成报告中复用，因此附件 SHA-256 可以重复，但每个文件仍必须与来源清单、数据库和槽位元数据一致。

## 来源与许可

逐项来源、作者、许可证、许可证链接、临床表现、尺寸、字节数、SHA-256 和隐私复核记录见：

- `backend/demo_media_sources.json`：处理后真实医学源素材；
- `backend/demo_media_manifest.json`：数据库 `storage_key` 到源素材、槽位和文件哈希的最终映射。

当前只接受 HTTPS 来源以及 Public Domain、CC0、CC BY、CC BY-SA 等允许再分发的许可。禁止许可不明、NC、ND、私人患者资料、AI 生成图和程序生成的伪医学影像。

## 处理与隐私

- 完整保留心电导联、超声结构、胸片肺野、肺功能坐标和显微画面；
- 低分辨率素材不放大，超大素材只等比缩小；
- 统一重新编码为 PNG，并清除 EXIF、IPTC、XMP；
- 不在图片像素中添加水印；
- 页面及机构批注显示“开放授权真实医学样例，仅用于功能展示，不对应系统用户，不作为诊断依据”；
- 不保留姓名、身份证、病历号、联系电话等患者身份字段。

## 重建与发布

本地重建从 `backend/demo_media_sources/` 复制已审核 PNG，不联网下载，也不会回退到合成色块图：

```powershell
cd backend
.\.venv\Scripts\python.exe scripts\reset_v7_demo_data.py --apply --yes
.\.venv\Scripts\python.exe scripts\refresh_demo_media.py --check-only
```

服务器媒体专项同步使用 `scripts/deploy-server.ps1 -SyncDemoMedia`。脚本在修改前备份数据库和上传目录，只更新清单中已存在的演示附件，并核对 19/15 数量、HTTPS 来源、许可证链接、标准槽位、文件格式、尺寸、SHA-256 和无 EXIF 状态；核心业务表行数必须保持不变。
