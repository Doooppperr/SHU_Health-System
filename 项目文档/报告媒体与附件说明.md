# 报告媒体与附件说明

## 1. 附件结构

系统当前包含 19 份体检报告附件，按标准槽位归档：

| 槽位 | 数量 | 检查类型 |
|---|---:|---|
| `US_THYROID` | 1 | 甲状腺超声 |
| `US_ABDOMEN` | 3 | 腹部超声 |
| `SPIROMETRY` | 2 | 肺功能图 |
| `ECG_12` | 5 | 十二导联心电图 |
| `CHEST_IMAGE` | 3 | 胸部影像 |
| `ECHO_HEART` | 2 | 心脏超声 |
| `BLOOD_MICROSCOPY` | 3 | 血细胞显微影像 |

附件与报告、健康方向、标准槽位和机构批注建立外键关联。附件主表和附件批注表使用相同的检查所见。

## 2. 文件与清单

- `backend/report_media/` 保存报告媒体母版。
- `backend/uploads/health-assets/` 保存系统实际读取的报告附件。
- `backend/report_media_manifest.json` 保存 storage key、槽位、检查类型、尺寸、字节数、SHA-256 和机构批注。

所有图片统一为 PNG，清除 EXIF、IPTC 和 XMP 元数据。清单校验会同时核对：

- 19 份报告附件和 15 张机构封面是否齐全；
- 文件能否正常解码；
- 文件尺寸、字节数和 SHA-256 是否与清单一致；
- 标准槽位、健康方向、检查类型和机构批注是否与数据库一致。

## 3. 临床批注

批注按照附件类型使用对应检查所见：

- 心电图：窦性心律，节律规则，未见明显 ST-T 异常。
- 心脏超声：各心腔大小未见明显异常，室壁运动协调，左心室收缩功能正常。
- 甲状腺超声：形态及大小正常，内部回声均匀，未见明确占位。
- 腹部超声：肝胆胰脾形态未见明显异常，未见明确局灶性病变。
- 胸部影像：双肺纹理清晰，未见明显活动性病灶，心影大小正常。
- 肺功能：曲线形态正常，未见明显阻塞性或限制性通气障碍。
- 血细胞显微影像：细胞形态及分布未见明显异常。

## 4. 重建与校验

```powershell
cd backend
.\.venv\Scripts\python.exe scripts\reset_v10_demo_data.py --apply --yes
.\.venv\Scripts\python.exe scripts\refresh_demo_media.py --check-only
.\.venv\Scripts\python.exe scripts\validate_v10_demo.py
```

服务器只刷新媒体时使用 `scripts/deploy-server.ps1 -SyncDemoMedia`；同步完整验收数据库时增加 `-SyncDemoDatabase`。发布脚本在更新前备份数据库、上传目录和环境配置。
