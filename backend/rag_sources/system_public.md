# HealthDoc 用户功能说明

HealthDoc 是面向访客、普通用户、体检机构和平台管理员的体检评价与健康管理平台。未登录访客可以浏览启用的机构、分院和已审核在售套餐；预约等业务操作需要登录。公共注册只创建普通用户账号，机构入驻不开放在线注册，由平台管理员在新建分院时创建唯一机构账号并向机构邮箱发送初始凭据。

普通用户首次登录后需要一次性确认姓名、性别和出生日期。确认后用户不能自行修改这些基本身份资料，如需更正由平台管理员处理；管理员可以查看和更正基本身份，但不能读取用户健康档案。未完成实名认证时，可以浏览公开和个人只读页面以及管理密码、邮箱，但不能测量、预约、评论、投诉或建立亲友关联。

用户可以记录日常测量，并在健康时间线、体检数据和健康趋势中查看当前账号的数据。趋势页将日常测量和已发布体检数据共同纳入分析，并单独显示异常指标、方向、参考范围、来源和是否已经恢复正常。普通用户不能自行上传机构体检报告。

亲友申请被对方接受后，双方成为双向关联账号。用户可以从头像菜单直接切换到关联账号，并在受控会话中按该账号操作；系统仍记录真实操作者、当前账号和完整关联链。最多连续切换三层，禁止循环。任何一方撤销关联、账号停用或密码安全版本变化都会使相关会话立即失效。

多人预约支持三种受检者：当前账号本人、已授权关联账号，以及凭健康身份码临时添加的用户。健康身份码只授予本次代预约资格，不建立亲友关系，也不授予账号切换或健康数据访问。匹配成功后只显示姓名、性别、出生年份和脱敏身份码；预约人不能修改平台身份资料。受检者可以在隐私设置中关闭健康身份码代预约。

所有预约按上海时区至少提前一天，最远可选择今天之后第30天。正式预约归入受检者自己的预约列表，原预约人另看脱敏代预约回执。预约卡片显示预约成功、到检、报告上传、待复核、报告发布或取消等进度。健康身份码代预约成功后无需受检者二次确认，但受检者会收到通知并可以取消自己尚未履约的预约。

机构先在草稿中录入或通过 OCR 解析报告。上传医生确认后报告进入待复核，复核医生可以修正内容；复核确认后报告发布并锁定，用户和同一机构主体的其他分院才可以查看。已发布报告不能修改或撤回，详情会展示上传医生、复核医生及相应时间。

用户可以针对每条个人预约提交一条投诉。机构回复后由用户确认解决；用户从提交投诉开始也可以随时申请平台管理员介入。升级后由平台管理员处理和关闭，机构不能继续操作。投诉只返回处理所需信息，不附带健康指标或报告正文。

用户拥有该机构发布的体检报告后可以发表评论。管理员隐藏评论时必须记录原因，并可以仅隐藏，或同时禁言7天、30天或永久禁言。每次处罚只能申诉一次；解封不会自动恢复已隐藏评论。禁言只影响发表评论，不影响预约、健康数据、报告和投诉。
